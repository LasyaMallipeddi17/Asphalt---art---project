## About the Project

For this project, I used Java and the Painter in Code.org to create an asphalt art design. My design is a duck made with colors black, yellow, and orange  on a 16 x 16 grid.

## How It Works

I created a CharacterPainter class that extended to  PainterPlus. I separated my project into different 3 methods called paintTop(), paintMiddle(), and paintBottom(). Each method paints a different part of my design.

I used methods such as move(), paint(), turnLeft(), and turnRight() to move the Painter around the grid and create my design.

## Output

My final output is a character made using black, yellow, and orange squares on a 16 x 16 grid.

## Reflection

This project helped me understand how subclasses and parentclasses work in Java. I learned that breaking a large design into smaller methods made my code easier to organize.

One challenge I had was getting the Painter to move to the correct squares and making the design look like my original drawing. I had to test my code and change some of the movements and colors until the design looked right.

If I did this project again, I would plan the location of each part of the design before I started coding. This would make it easier to keep the design proportional.
